# Session Summary: Permission System & Setup Flow (2026-06-13)

## What Was Done

This session implemented a **permission system** and **bidirectional setup flow** to fix the issue where the bot was replying to everyone, not just the owner.

### Phase 2 Changes: Permission-Based Access Control

#### Problems Solved
- ❌ Bot was replying to EVERYONE who texted
- ❌ No control over who uses the bot
- ❌ No onboarding flow for users
- ✅ **Now**: Only authorized users get responses

#### Key Implementations

1. **Permission Database Column**
   - Added `has_permission` boolean to `users` table
   - Owner always has permission (`is_owner=true` → auto `has_permission=true`)
   - New users start with `has_permission=false`

2. **Webhook Permission Check**
   - Runs BEFORE Hermes dispatch
   - If user is not owner AND not authorized → sends "Setup mode" message
   - If owner hasn't completed OAuth → prompts for setup

3. **Permission Management API**
   - `GET /permissions` — List all users + status
   - `POST /permissions/grant?phone=...` — Owner grants access
   - `POST /permissions/revoke?phone=...` — Owner revokes access

4. **Owner Dashboard** (`/dashboard`)
   - Web UI for managing user permissions
   - Shows all users who've texted
   - One-click grant/revoke buttons
   - Real-time updates every 10 seconds

5. **Chat-Based Setup Commands**
   - "STATUS" → shows setup progress
   - "OAUTH" → returns Google auth link
   - "SETUP" → returns web setup link

6. **Domain Changed**
   - Updated all references from `http://localhost:8000` to `https://api.narendar.tech`
   - Updated Google OAuth redirect URI
   - All setup messages now use the new domain

### What Works Now

1. **Owner Setup**
   ```
   Owner scans QR → is_owner=true
   Owner clicks OAuth → tokens stored
   Owner visits /dashboard → sees all users
   ```

2. **New User Flow**
   ```
   User texts bot → created with has_permission=false
   User gets → "🔒 This bot is currently in setup mode"
   Owner grants permission → has_permission=true
   User texts bot → now gets Hermes responses
   ```

3. **Chat-Based Fallback**
   ```
   User: "OAUTH" → Bot: "Visit {BASE_URL}/oauth/authorize"
   User: "STATUS" → Bot: "Setup Status: awaiting_oauth"
   User: "SETUP" → Bot: "Visit {BASE_URL}/setup"
   ```

## Endpoints Reference

### Setup (Owner only):
- `GET /setup` — Setup UI with QR + Google button
- `GET /setup/qr-status` — Check QR status
- `GET /setup/qr-image` — Download QR code

### Permissions (Owner only):
- `GET /permissions` — List all users
- `POST /permissions/grant?phone=...` — Grant permission
- `POST /permissions/revoke?phone=...` — Revoke permission
- `GET /dashboard` — User management UI

### OAuth:
- `GET /oauth/authorize` — Redirect to Google login
- `GET /oauth/callback` — Google callback (auto-handled)

### Core:
- `POST /webhook/openwa` — WhatsApp webhook (Evolution API)
- `GET /health` — Health check
- `GET /` — API info
